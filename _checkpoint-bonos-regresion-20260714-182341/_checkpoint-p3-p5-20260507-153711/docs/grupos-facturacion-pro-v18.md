# v18 - Recuperacion de grupos + facturacion PRO

Corrige la v17 para no perder grupos y añade facturacion PRO de grupos.

- Mantiene grupos genericos.
- Mantiene pacientes fijos.
- Mantiene clases sueltas.
- Añade facturacion de grupos.
- Fijos = pacientes fijos x precio mensual.
- Sueltas = clases sueltas del mes x precio suelta.
- Boton Facturar mes.
- Evita doble facturacion mensual.
