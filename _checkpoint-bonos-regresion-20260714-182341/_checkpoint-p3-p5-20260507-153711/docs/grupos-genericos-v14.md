# v14 - Grupos genericos recurrentes

Esta version convierte las clases grupales en un modulo general de Grupos.

## Incluye
- Boton Nuevo grupo funcional en Configuracion.
- Alta de grupos para Pilates, Yoga, CrossFit u otros servicios.
- Servicio, trabajador, sala, dias, hora, capacidad y pacientes inscritos.
- Bloqueo visual en Agenda dia/semana/mes.
- Control de conflictos: no deja crear una cita individual si choca con un grupo por sala o trabajador.
- Listado de grupos en Configuracion con plazas ocupadas/libres.

## No toca backend
Sigue siendo frontend/localStorage para evitar lios con la API actual.
