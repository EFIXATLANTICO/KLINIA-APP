# v16 - Pacientes fijos en grupos y clases sueltas

Esta version mejora la gestion de grupos recurrentes.

## Incluye

- Añadir pacientes fijos desde la ventana del grupo.
- Quitar pacientes fijos del grupo.
- Mantener las clases sueltas por dia.
- Evitar duplicados entre fijos y sueltos.
- Actualizar contador: fijos + sueltos / plazas.

## Uso

1. Ir a Agenda.
2. Abrir una clase de grupo.
3. En Pacientes fijos, seleccionar un paciente y pulsar Añadir fijo.
4. Para una clase puntual, usar Añadir clase suelta.

Los pacientes fijos ocupan plaza en todas las clases recurrentes del grupo.
Las clases sueltas solo ocupan plaza ese dia.
