# V15 - Grupos editables y clase suelta

Esta version mejora el modulo de Grupos para que funcione como una herramienta real de gestion de clases recurrentes.

## Incluye

- Editar grupos ya creados desde Configuracion.
- Eliminar grupos y limpiar sus clases sueltas asociadas.
- Gestionar grupo desde Configuracion.
- Abrir clase grupal desde la Agenda.
- Ver pacientes fijos inscritos.
- Añadir pacientes de clase suelta para un dia concreto.
- Quitar pacientes sueltos del dia.
- Control de plazas disponibles: pacientes fijos + sueltos / capacidad.
- Mantiene bloqueo de sala y trabajador para evitar solapes.

## Uso recomendado

1. Crear pacientes desde Pacientes.
2. Crear servicio grupal: Pilates, Yoga, CrossFit, etc.
3. Crear grupo recurrente desde Configuracion > Grupos.
4. Asignar pacientes fijos al grupo.
5. En Agenda, abrir la clase y anadir pacientes sueltos si hace falta.

## Importante

La clase suelta se guarda solo para el dia seleccionado en la agenda. No modifica la lista de pacientes fijos del grupo.
