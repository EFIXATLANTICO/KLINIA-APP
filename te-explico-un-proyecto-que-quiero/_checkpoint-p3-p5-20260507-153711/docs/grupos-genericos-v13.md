# v13 - Grupos genericos

Esta version sustituye el enfoque especifico de Pilates por un modulo generico de grupos.

## Enfoque recomendado

- **Servicios**: definen el tipo de actividad: Pilates, Yoga, CrossFit, etc.
- **Grupos**: definen una clase recurrente con dia, hora, sala, trabajador, capacidad y pacientes inscritos.
- **Citas**: quedan para sesiones individuales o citas puntuales.

## Que incluye

- Panel de Grupos dentro de Configuracion.
- Creacion de grupos recurrentes asociados a cualquier servicio grupal.
- Inscripcion de pacientes fijos al grupo.
- Bloqueo visual en Agenda dia, semana y mes.
- Control de plazas ocupadas/libres.
- Detalle del grupo desde agenda.
- Base para facturacion mensual por paciente y clase suelta.

## Recomendacion

No crear un modulo exclusivo de Pilates. Usar Grupos genericos permite vender el producto a clinicas con Pilates, Yoga, CrossFit, readaptacion grupal o talleres.
