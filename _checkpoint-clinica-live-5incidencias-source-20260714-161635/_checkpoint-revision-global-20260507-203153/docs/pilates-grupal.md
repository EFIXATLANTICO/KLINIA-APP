# Pilates grupal en Klinia

Esta versión añade configuración de servicios grupales para pilates o clases reducidas.

## Qué se puede configurar

- Tipo de servicio: individual o clase grupal.
- Número máximo de integrantes.
- Precio mensual por paciente.
- Precio de clase suelta.
- Porcentaje que se lleva el trabajador por paciente en la clase.

## Cómo usarlo

1. Entra en Configuración.
2. Pulsa Nuevo servicio.
3. Elige Clase grupal / Pilates.
4. Rellena capacidad, mensualidad, clase suelta y comisión.
5. Crea citas usando ese servicio.

## Facturación

Para una cita grupal, la app calcula el importe como:

`asistentes x precio de clase suelta`

Si no hay precio de clase suelta, usa el precio base del servicio.
