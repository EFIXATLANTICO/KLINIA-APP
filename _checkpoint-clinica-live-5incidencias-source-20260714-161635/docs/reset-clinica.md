# Reset limpio de clinica

Este parche mejora el comportamiento de `Resetear datos de esta clinica`.

## Que corrige

- Mantiene la cuenta de la clinica para poder volver a entrar.
- Borra pacientes, citas, notas, servicios, trabajadores y salas.
- Limpia datos auxiliares de recordatorios, historial y automatizaciones si existen.
- Reinicia la vista de Rendimiento cuando no hay trabajadores ni citas.
- Evita que se quede en pantalla actividad antigua tras resetear.

## Uso recomendado

1. Entra como Direccion.
2. Ve a Configuracion.
3. Pulsa `Resetear datos de esta clinica`.
4. Confirma.
5. Vuelve a revisar Pacientes, Agenda, Automatizaciones, Facturacion y Rendimiento.

La clinica seguira apareciendo en el selector de acceso, pero sus datos operativos quedaran limpios.
