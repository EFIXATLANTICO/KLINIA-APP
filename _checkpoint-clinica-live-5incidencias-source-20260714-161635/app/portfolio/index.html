Sobre el proyecto

Un SaaS real para operar clínicas privadas

Problema

Muchas clínicas gestionan agenda, bonos, pacientes, cobros y rendimiento en herramientas separadas. Klinia centraliza la operativa diaria y reduce errores administrativos.

Usuarios

Dirección, recepción, trabajadores y soporte SaaS. Cada perfil necesita una experiencia distinta, con permisos y datos separados por clínica.

Diferencial

Combina producto, facturación interna, suscripción SaaS, PWA multidispositivo, roles y panel superadmin en una sola plataforma preparada para crecer.

Funcionalidades principales

Módulo a módulo, pensado para uso diario

Una base funcional amplia para operar clínicas reales, con foco en consistencia de datos y usabilidad.

Arquitectura técnica

Frontend ligero, backend API y datos persistentes

Frontend HTML · CSS · JavaScript

Interfaz responsive, PWA, service worker y experiencia multidispositivo.

Backend FastAPI · Python

API de autenticación, clínicas, usuarios, auditoría, Stripe y datos operativos.

Base de datos PostgreSQL

Persistencia real, separación por clínica y preparación multi-tenant.

Infraestructura Render · Vercel

Backend público, frontend desplegado, dominio propio y configuración de producción.

Pagos Stripe

Checkout, portal, webhooks y estado de suscripción SaaS.

Acceso JWT · Google Login

Login tradicional compatible con Google OAuth, roles y recuperación de acceso.
